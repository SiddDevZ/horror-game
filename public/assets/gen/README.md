# generated assets (gpt-image via mchat)

Made with the `gpt-image-mchat` skill (`~/.claude/skills/gpt-image-mchat`): model **gpt-image-2** through the local mchat gateway
(`POST http://127.0.0.1:8317/v1/images/generations`), generated **2026-09-27**. Reproduce with
`node scripts/gen-assets.mjs [id|kind ...] [--force]` (raw PNGs go to `/tmp/horror-gen-raw`), then `node scripts/gen-post.mjs`.
Generation is not deterministic, so a rerun gives different images.

## how to use

- **icons.png + icons.json**: a 4-column atlas of 32x32 cells in true pixel art (1 texel = 1 art pixel). Draw with
  `image-rendering: pixelated`, `imageSmoothingEnabled = false` or `NearestFilter`, at an integer scale (x2 = 64 px, x3 = 96 px; the hearts use 3 screen px per art pixel).
  `icons.json` is `{ cell, cols, rows, icons: { id: { x, y, w, h, col, row } } }`. Each cell is also saved separately in `icons/*.png`.
  Each icon is centred in its cell and measures 11-31 px on its long side. The skull, breaker and compass are smaller natively.
- **logo.png**: a native 114x26 pixel-art "LEVEL 0" title on a transparent background. Scale it by an integer with nearest-neighbour (x4 = 456x104, x6 = 684x156).
- **posters/*.webp**: 512x711 (0.72 portrait), opaque, ready to pack into the poster atlas.
- **labels/*.webp**: `vhs_label.webp` is 512x288 with transparent rounded corners (VHS cassette face label). `almond_water_label.webp` is a 768x384 opaque wrap label for the bottle.

## post-processing

- **Icons.** The model returns 1254x1254 "pixel art" whose fake pixels are about 35-50 px wide. `pixelize.py` detects that pitch from the spacing of hard colour edges and samples each cell (median of its centre). It then thresholds alpha at 128, drops islands smaller than 3 cells, quantizes to 16 colours and centres the result on 32x32, with the long side capped at 31 cells.
- **Checkboxes** are drawn procedurally in `gen-post.mjs` (Minecraft slot bevel, heart outline colour `#1b0707`). Generating them would not have looked better.
- **Logo.** The same pixelizer runs with an alpha threshold of 200 to drop the soft glow and a 24-colour palette. Bright crumbs left on the outer edge are then stripped.
- **Posters** are centre-cropped to 0.72. The exception is the almond water poster: its text reaches the top and bottom edges, so it is widened with flat paper colour instead.
